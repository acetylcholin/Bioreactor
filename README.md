
# Fermentor Control System

Web-based fermentor / bioreactor control software running on Raspberry Pi.

## Features
- Temperature (Atlas EZO RTD)
- pH (Atlas EZO pH, temperature compensated)
- Real-time web dashboard
- Modular device architecture
- WebSocket live updates

## Tech Stack
- Node.js (ES modules)
- Express
- WebSocket (ws)
- Raspberry Pi
- I²C sensors
